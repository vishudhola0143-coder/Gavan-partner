# Raw

Footage waiting to be edited — **one folder per video**.

Example:

```
Raw/
  2026-11-24-site-visit/
    clip1.mp4
    clip2.mp4
    notes.md   <- optional: topic, key points, platform (Reel/Short/YouTube), deadline
```

Name each folder with the date and a short title so it's easy to match to its export.
