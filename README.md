# Gavan Group — Website

Official website of **Gavan Group · The Key of Luxury** (South Gujarat).
Real Estate · Interior · Hospitality · Startups · Gavan Foundation.

## Open it
Open `index.html` in any browser — no build step or server needed.
It can be hosted as-is on GitHub Pages, Netlify, Vercel or any static host.

## Update content (no coding)
All changing content lives in **`assets/js/content.js`**:

| What | Section in file |
|---|---|
| WhatsApp number, phone, email, address | `contact` |
| Instagram links & follower counts | `social` |
| Projects (residential / commercial / industrial) | `projects` |
| Startups (UltraRad AI, View Box, Contrast) | `startups` |
| Events & news (shown as "Live updates") | `updates` |
| Future plans | `roadmap` |

Any text can be written as `'English'` or `{ en: 'English', hi: 'हिन्दी', gu: 'ગુજરાતી' }`.
The site opens in English, with an EN / हिं / ગુ language switch in the header.

## Files
- `index.html` — page structure and fixed text
- `assets/css/style.css` — design
- `assets/js/content.js` — editable content
- `assets/js/desk.js` — Property Desk: government links, news (edit here)
- `assets/js/main.js` — behaviour (language switch, WhatsApp enquiry, filters)
- `partner-workspace.html` — internal partner workspace app (linked as "Partner login" in footer)
