# AI Video Editing Studio

| Folder | What goes in it |
|---|---|
| `References/` | Videos whose style you like |
| `Approved Videos/` | Your finished edits |
| `Editing Style/` | Written editing rules / style guide |
| `Brand Kit/` | Logos, colors, fonts, intros/outros, music |
| `Raw/` | One folder per video you want edited |
| `Exports/` | Finished renders, ready for review |

Workflow: add footage to a new folder in `Raw/` → edit using `Editing Style/`, `Brand Kit/`,
`References/` and `Approved Videos/` as guidance → render to `Exports/` → move approved
edits to `Approved Videos/`.
